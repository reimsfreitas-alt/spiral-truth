# Checklist de publicação — Spiral Truth V1.1.1

## Reinaldo precisa executar manualmente

- [ ] Criar um repositório GitHub próprio, por exemplo `spiral-truth-v1.1.1`.
- [ ] Extrair o ZIP.
- [ ] Enviar `index.html`, `README.md`, `LICENSE` e `LAUNCH-PACK.md`.
- [ ] Criar um projeto Vercel conectado ao novo repositório.
- [ ] Usar configuração estática: framework Other, sem build command.
- [ ] Fazer o deploy.
- [ ] Informar a URL pública.
- [ ] Testar no celular.
- [ ] Testar o botão Stripe.
- [ ] Confirmar como o comprador receberá o acesso.

## Validação antes de anunciar

- [ ] A página abre sem erro.
- [ ] O Live Lab funciona.
- [ ] O tamper test funciona.
- [ ] A verificação de integridade funciona.
- [ ] As exportações funcionam.
- [ ] O botão de pagamento aponta para o link correto.
- [ ] As limitações aparecem antes da compra.
- [ ] Não há promessa de execução externa ou auditoria formal.
