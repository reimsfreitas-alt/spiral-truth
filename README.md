# Spiral Truth V1.1.1

## Founder / Proof-of-Concept

O Spiral Truth V1.1.1 é um Live Lab local para explorar a diferença entre:

- intenção;
- política;
- autorização;
- execução declarada;
- evidência;
- reconciliação;
- desvio;
- receipt.

## O que esta versão demonstra

- registro local de eventos;
- encadeamento por SHA-256;
- verificação de integridade;
- teste interativo de adulteração;
- exploração de condições e tolerâncias;
- exportação de relatórios;
- experiência de laboratório executada no navegador.

## Limitações explícitas

Esta versão não deve ser tratada como infraestrutura enterprise ou auditoria formal. Ela não fornece:

- backend persistente multiusuário;
- isolamento corporativo por organização;
- integração operacional com ERP, sensores ou APIs externas;
- observação independente de sistemas de terceiros;
- assinatura Ed25519;
- execução externa real;
- garantia de retenção permanente dos dados;
- certificação ou conformidade regulatória.

## Execução local

Abra `index.html` em um navegador moderno.

Para publicação estática, o arquivo pode ser servido por qualquer hospedagem compatível com HTML estático.
